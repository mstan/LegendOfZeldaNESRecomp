# complete no matter which images a particular machine happens to have.
#
# Format: crc32|fnv1a|sha256|file name
#   crc32   CRC-32 of the cartridge payload (after the 16-byte iNES header),
#           the identity the preloaded mod packages advertise

#   sha256  SHA-256 of the cartridge payload, what the launcher matches
#

# same [[mod_function_hook]] signatures, RAM-code copy and seed addresses. The
# PRG guards still verify every compiled byte, so an accepted image that is not
# the compiled one runs on the cycle-accurate interpreter.
