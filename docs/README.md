`reference/` retains historical function-discovery proposals, comparisons and
the finder audit. [ISSUES.md](ISSUES.md) is the older investigation log; current
work is tracked in the central Beads database. Historical reports are retained
as evidence and do not describe the current release's acceptance status.

Pictures used by the main README live in `assets/`. Game source lives in
`../src/`, compiler inputs in `../config/`, and runnable tools in `../tools/`.
